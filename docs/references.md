# 모델링 참고자료

자료 확인일은 2026년 9월 13일이에요. 웹페이지 게시일이 사진 촬영일을 뜻하지는 않아요.

공식 전경 이미지 원본은 검색으로 주소를 확인했지만 직접 가져오기가 실패했어요. 따라서 사진의 세부 형태는 사용자가 제공한 이미지를 기준으로 삼았어요. 제공 이미지 속 기사 제목이나 광고 문구는 작업 지시로 취급하지 않았어요.

## 추정한 부분

- 정확한 축척과 높이, 건물 깊이, 지형의 고저차
- 사진에 나타나지 않는 뒷면과 연결부, 별동의 형태와 위치
- 부지 경계, 다목적 코트의 위치와 도색, 주차 구획과 조경
- 내부 공간, 구조 부재의 구분과 지지 관계

외벽의 인상과 알아볼 수 있는 특징을 우선한 재구성이에요. 정확한 캠퍼스 복원에는 촬영 시점이 확인되는 최근 항공 사진, 후면·측면 사진과 전체 배치도가 필요해요. 구조 해석 수준의 재난 예측에는 별도의 전문 자료와 검증이 필요해요.

## 2026년 9월 19일 배치 보완

사용자가 추가 제공한 전경 1장, 위성사진 3장, 2024년 1월 표시가 있는 로드뷰 3장을 기준으로 보완했어요. 운동장은 동서 약 52, 남북 약 70 게임 단위로 조정했고, 서쪽 흰색 기숙사와 남서쪽 주황색 강조 기숙사를 구조 부재로 추가했어요. 창의융합동은 본관 뒤의 긴 동과 비스듬한 뒤쪽 동으로 확장했어요. 동쪽에는 테니스장 두 면과 그 북쪽 다목적 코트, 남쪽 주차 공간을 배치했어요. 위 치수는 실측값이 아닌 사진 비율에 따른 추정이에요.

인접한 단재교육연수원 건물은 학교 건물로 취급하지 않았어요. 주변 농경지의 색·구획, 산의 높이, 기숙사 지붕과 뒷면은 단순화했어요. 사진의 시점을 넘어 모든 현재 건물이 확인되었다고 보장하지는 않아요. 이번 자료로 위치를 확인한 시설들은 앞 절의 위치 추정 범위를 대체해요.

추가 확대 위성사진과 사용자 설명에 따라 흰색 기숙사를 운동장 남쪽 밖까지 연장하고 남쪽으로 꺾인 반환부를 추가했어요. 주황 지붕 기숙사는 그 끝에 이어지는 동과 짧은 측면 동으로 구성했어요. 창의융합동 사이와 본관 뒤에는 닫힌 연결 건물을 추가했어요. 모든 추가 학교 건물과 연결부는 파괴 가능한 구조 부재예요.
