# 물리 모델

이 프로젝트는 시각적으로 설득력 있는 붕괴를 목표로 하는 게임이에요. 실제 학교의 구조 해석이나 재난 피해 예측을 위한 수치 모델은 아니에요.

## 계산 방식

- 장면 단위는 대략 1m, 중력은 −9.81m/s²예요. Rapier는 조각의 질량·관성·접촉·마찰·충돌을 계산해요.
- 벽·바닥·기둥·전면 유리는 처음에는 고정 강체예요. 손상이 임계값에 도달하거나 지지 능력을 잃으면 동적 강체로 바뀌어요.
- 지지 연결의 남은 능력이 원래의 40% 미만이면 0.26~0.76초 지연 뒤 해당 부재가 떨어져요. 지연은 부재 ID에서 계산되며 매번 같아요.
- 지지 상태는 한 번에 판정한 뒤 반영해 배열 순서에 따른 즉시 전체 붕괴를 피했어요. 떨어진 부재의 충돌은 주변에 추가 손상을 줄 수 있어요.
- 고정 시간 간격 1/60초로 계산해요. 낮은 프레임에서 무한히 계산이 밀리지 않도록 한 렌더 프레임에 최대 6단계만 수행해요. 느린 기기에서는 실제 시간보다 천천히 진행될 수 있어요.
- 동일한 초기 상태와 실행 순서를 반복하면 같은 난수 흐름과 물리 초기 상태를 사용해요. 다른 브라우저·CPU 간 완전히 동일한 부동소수점 결과까지 보장하지는 않아요.

## 재난별 작용

| 계열                       | 적용한 작용                                                          | 생략·근사한 부분                                          |
| -------------------------- | -------------------------------------------------------------------- | --------------------------------------------------------- |
| 운석·폭발·추락             | 거리 감쇠 충격, 조각의 비산, 지지 손실, 후속 열                      | 운석 관입, 지반 크레이터, 화학 반응, 압축성 충격파 전파   |
| 지진                       | 여러 주파수의 지반 가속도에 따른 관성 하중과 높이별 손상             | 실제 지진 기록, 토양과 기초의 상호작용, 공진 해석         |
| 홍수·지진해일              | 수면 아래의 비율, 부력, 속도 차에 따른 항력, 흐름에 의한 손상과 냉각 | 유체 입자/격자 해석, 건물에 막히는 유동, 침식과 누수      |
| 화재·낙뢰·화산             | 열 축적, 가연물 사이의 전열, 재료 강도 저하, 투사체 충격             | 내부 가연물 전체, 산소와 연기 확산, 전기 회로와 방전 해석 |
| 토네이도                   | 중심으로 향하는 힘, 접선 방향의 힘, 상승력                           | 실제 기압장과 공기역학적 차폐                             |
| 거대 우박                  | 여러 작은 충격, 약한 전면 유리의 분리                                | 미세한 균열, 얼음 변형·융해                               |
| 블랙홀·중력 반전·외계 침공 | 가상의 인력장·상승력·빔 충격과 열                                    | 일반상대론이나 실재하는 물리 현상 재현                    |

재난 강도 1~20은 게임용 조절 값이에요. 1~5의 기본 범위를 넘어가면 비선형 배율을 적용하며, 20에서 추가 배율은 12가 돼요. 재난마다 이 배율을 반경·힘·열 등에 다르게 적용하므로 실제 에너지의 12배라는 뜻은 아니에요. 실제 지진 규모, 폭약량, 수심별 구조 안전 기준과 대응하지 않아요. 재료의 밀도는 질량 비율을 만드는 근삿값이며 강도·열 파괴 값은 실제 자재 시험 결과가 아니에요.

강한 충격에서 잔해 속도가 기존 상한에 묶이지 않도록 조정했어요. 여러 충격을 겹칠 때도 계산이 발산하지 않도록 강체의 선속도와 회전 속도는 제한하고, 연속 충돌 감지의 추가 단계를 사용해요. 물리 지면도 확장해 멀리 날아간 조각의 낙하와 충돌을 계속 계산해요. 조각을 순간이동시켜 비산을 표현하지 않아요.

운석의 지름·구성과 속도는 모형뿐 아니라 충격의 기준 질량·힘·반경에도 반영돼요. 나머지 재난의 수면·수류·열원·투사체·가상 인력장도 해당 세부 설정을 사용해요. 실행할 때 설정을 복사하므로 이후 값을 편집해도 이미 진행 중인 재난의 조건은 바뀌지 않아요.

전면 유리는 독립 조각으로 떨어지지만 미세한 유리 파편으로 분쇄되지는 않아요. 건물 조각은 미리 나누어져 있어 충격 지점에서 새 균열을 계산하는 연속체 파괴는 수행하지 않아요. 장식용 산·나무·차량·골대와 지형은 고정돼 있어요. 사람과 인명 피해는 모델에 포함하지 않았어요.

## 검증

`npm test`는 정지 상태 안정성, 지지 손실의 지연 붕괴, 부분 지지 유지, 잔해 충돌에 따른 추가 피해, 열 전달·물의 냉각과 부력, 초기화 재현성, 14종 재난의 수명과 반복 실행 등을 검사해요. 실제 부재 강도를 검증하는 시험은 아니에요.

[Rapier 강체 문서](https://rapier.rs/docs/user_guides/javascript/rigid_bodies/)와 [Three.js 문서](https://threejs.org/docs/)를 참고했어요.
